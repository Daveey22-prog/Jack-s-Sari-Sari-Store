# Jack's Sari-Sari Store POS

A standalone browser-based Point of Sale system made for the TLA 3 "Using Free POS" demonstration.

## How to use
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome, Microsoft Edge, or Firefox.
3. Go to Point of Sale.
4. Select products and quantities.
5. Choose Cash, GCash, or Card.
6. For Cash, enter the amount received.
7. Click Complete Sale.
8. Print the generated receipt if needed.
9. Sales History stores completed transactions in the browser's local storage.

## Included
- Point of Sale screen
- Product catalog and categories
- Search
- Shopping cart
- Cash / GCash / Card payment
- Automatic change calculation
- Printable receipt
- Products list
- Inventory dashboard
- Low-stock status
- Sales history
